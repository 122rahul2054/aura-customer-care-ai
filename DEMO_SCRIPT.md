# 3–5 minute demo outline

0:00–0:30: Introduce Aura, Java Spring Boot and React. Show the Start Call control and visible sample orders.

0:30–1:20: Start call. Say “Where is my order ORD-101?” Show Listening, Thinking and Speaking. Confirm BlueDart and the 6 PM estimate. Expand the lookup trace to show real Java tool execution.

1:20–2:05: Ask “Can I return ORD-102?” Explain that the 14-day delivered order is outside the policy. Ask “Can you cancel ORD-103?” Confirm eligibility without claiming cancellation occurred.

2:05–2:40: Ask about ORD-999 and then an unrelated request. Demonstrate graceful handling.

2:40–3:15: End call, show chronological transcript and JSON outcome. Download JSON.

3:15–4:30: Show ApiController, CallService tool loop, OrderService and AiService. Explain key protection, session isolation, full model-history preservation, policy ambiguity at exactly INR 499, and browser voice limitations.

Before recording: use a configured key, working browser, HTTPS/localhost, headphones, and close any screen containing secrets. Record a real successful run; do not present mocked tests as live AI proof.
